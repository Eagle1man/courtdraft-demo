Публикация на сайт

Сборка .fet → проверка → выгрузка JSON для сайта.

Выгрузки

Что получает сайт

POST read-file-groups.php
  do=groups            → {"Академия": {"Группа": 1}}
  do=schedule&group=X  → {"X": ["дд.мм.гггг - дд.мм.гггг", {"10": [мета, {день: {пара: [...]}}]}]}

Экспорт панели делает ровно эти структуры, поэтому сайт читает расписание без переписывания. Дополнительно собирается автономный просмотрщик — его можно открыть на ВМ и поставить ссылкой с сайта.

Как это устроено

  1. AVTORнедельники и справочники учебной части
  2. ETLCP1251 → SQLite, каждая строка с источником
  3. FET 7.10сборка .fet и проверка реальным fet-cl
  4. ПубликацияJSON в формате сайта + автономный просмотрщик
  5. Человекпроверяет конфликты и принимает решение
